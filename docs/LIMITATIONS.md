# Limits that matter to a reviewer

- Independent prototype, not affiliated with Google/YouTube and not a native TV application.
- One original lesson; no broad video catalog or multimodal video comprehension.
- Authored text acceptance tasks, not independent held-out evaluation, measured speech accuracy or human usability evidence.
- Public browser path is deterministic. Real local-model inference is available through the Python host; public model runs are recorded.
- An exact excerpt can still be the wrong excerpt for the user's question. Source fidelity is not intent correctness.
- Public QR card is shareable, does not expire, and contains no private data. Local single-use API is separate and loopback-only.
- No production multi-device pairing, authenticated account actions, device integrations, measured retention, revenue uplift, employer adoption or client influence.
- Latest 54/54 is an authored development-suite result that includes 16 deterministic boundary decisions. It does not establish generalization, unconstrained reasoning or an advantage over the equally successful rules baseline.
- TV focus mode and fixed browser viewports are not physical device certification; software QR decoding is not a phone camera test.
- The model may fail, be slow, choose the wrong action or misunderstand ambiguity. All measured failures remain visible.
- No self-awarded perfect score. Engineering tests establish specific contracts, not universal product quality or hiring fitness.
